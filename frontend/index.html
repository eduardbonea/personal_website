RoID Hub

RoID Hub is a web-based application designed to read, manage, and use data from the Romanian Electronic Identity Card (CEI) in secure digital workflows.

The platform allows users to securely access personal data and qualified certificates stored on the CEI via the official PKCS#11 library. Users can view the identity information extracted from the card, edit relevant details when preparing documents, and digitally sign one or multiple PDF files with visual signature placement.

RoID Hub supports ECDSA certificates issued for CEI and enables direct download of signed documents after processing. The application can be deployed on a Linux-based web server or run locally on Windows, making it suitable for both organizational environments and individual professional use.
