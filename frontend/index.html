ITP App

Majoritatea staților ITP nu au o modalitate de gestiune a vizitelor. Prin această aplicație aceștia pot gestiona programările stocate într-o bază de date cu ajutorul unui formular. Urmând ca apoi un API să trimită un SMS numarului de telefon introdus în câmpul specific prin care anuntă clientul că este așteptat la serivce la ora stabilită tot prin formular. Tehnologiile folosite fiind React + Vite pentru Front-End și Node.js pentru Back-End cu framework-urile Express.js si Sequelize.js
